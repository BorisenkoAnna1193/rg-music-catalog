# Обновление из Википедии: новые сезоны и правки старых данных

- **Дата:** 2026-10-20
- **Шаги конвейера:** 1/6 (выгрузка), 7 (слияние), 19 (родная Википедия); новый шаг 22 — обновление

## Запрос владелицы
Если кто-то правит статью в Википедии и наши данные за старые годы начинают расходиться — выводить предупреждение, чтобы
владелица проверила, и ничего в базе не обновлять просто так. Нужен механизм добавления данных: новый сезон начинается
в январе, у гимнасток появятся новые строки с музыкой.

Решения владелицы (2026-10-20): музыка там, где её не было (новая строка, пустая ячейка, «??» и подобные заглушки), в
любом году добавляется сразу и показывается списком (можно отклонить); на проверку уходит только замена уже известной
музыки (и её удаление); запуск вручную по команде.

## Что сделано
- Новый шаг 22 `rg_music/update.py`: ревизии всех 558 отслеживаемых статей (533 английских + 25 испанских/русских) по 50
  за запрос; изменившиеся статьи скачиваются в `data/raw/_update/` (основной кэш не трогается); строки сравниваются по
  содержанию (год, предмет, музыка, соревнование), а не по номеру строки.
- Правило (уточнено с владелицей по ходу, после находки task-verifier про заполняемые заготовки): `new_music` = музыка
  там, где её не было (новая строка или заполненная заглушка «», «??», «Unknown»…), в любом году → принимается сразу
  (`decided_by = rule`) и остаётся в листе, пока владелица не просмотрела (`reviewed`); `changed` / `removed` = известная
  музыка заменена или пропала → `update_review.csv`, в базе ничего не меняется до решения. Изменения без музыки с обеих
  сторон не считаются.
- Решения: `data/manual/wiki_updates.csv` (строки JSON), применяются в `merge.py` поверх сырых файлов; отклонённое не
  показывается снова; принятое, чья старая строка пропала → `unused_owner_rows`.
- `update --import <csv>`: accept / reject (или принять / отклонить), сверка музыки с `update_staged.json`.
- `extract.py`: разбор статьи вынесен в `page_rows()` (его использует update); `wiki_client.revids()`.
- Первый настоящий запуск (2026-10-20): изменились 47 статей из 558, 6 строк новой музыки
  добавлено по правилу (Verdeș 2026 обруч; Mirano Kita 2026 четыре предмета; Ilteriakova 2027 обруч), изменений прошлых лет
  нет. После `pipeline --from merge`: выступлений 4191 → 4197, произведений 2593 → 2595, версий 2946 → 2948.
